# VUT CourseCorrect

A tutoring website for Vaal University of Technology students. Browse courses, book a tutor, and contact the team. Available in English and Afrikaans.

**Live website:** [https://coursecorrect.rf.gd](https://coursecorrect.rf.gd)

**Author:** Keletso

## How to run it

1. Install [XAMPP](https://www.apachefriends.org/).
2. Copy this project folder into `C:\xampp\htdocs\`.
3. Copy `smtp_config.example.php` and rename the copy to `smtp_config.php`. Add your Gmail address and App Password (this is only needed for emails).
4. Open the XAMPP Control Panel and click **Start** next to **Apache**.
5. Open your browser and go to:

   **http://localhost/VutCourseCorrect/**

That's it!
