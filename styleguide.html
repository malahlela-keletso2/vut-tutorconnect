Brand Style Guide

The rules that keep every page of VUT CourseCorrect consistent, readable and accessible.

Colour Palette

SwatchNameHexUsed for
AaPrimary Blue#012EACBanner, buttons, table headers, footer
AaDeep Blue#011F73Navigation bar, headings
AaGold Accent#ECA702Active/hover states, borders, call to action
AaInk#0A1640Body text
AaLight Blue#E6ECFBPage background, feature boxes
AaFooter Link Gold#FFC53DLinks on dark backgrounds
AaSuccess Green#2E9E4FEngineering faculty accent
AaAlert Red#D32F2FHumanities faculty accent

Typography

ElementFontSizeWeight
Page title (h1)Poppins2.2em - 2.5em700
Section heading (h2)Poppins1.8em600
Card heading (h3, h4)Poppins1.1em - 1.2em600
Body textOpen Sans1em (line-height 1.6)400
Navigation and buttonsOpen Sans1em600

Fallbacks: Segoe UI, Calibri, then any sans-serif. Each page has exactly one <h1>.

Layout and Spacing

  • Maximum content width: 1200px
  • Card padding: 25px - 40px, border radius 8px
  • Section spacing: 40px
  • Breakpoints: 1024px, 768px and 480px

Components

  • Navigation: deep blue bar, white text, no underline, gold hover and active state, dropdown for Courses and About
  • Buttons: primary blue with white text; call to action gold with ink text
  • Forms: labelled fields, blue 2px fieldset border, blue focus border
  • Footer: business name, address, phone, social links, copyright

Naming Conventions

  • Page and image files use lowercase letters and hyphens, no spaces, e.g. about.html, background-1.jpg.
  • Afrikaans pages live in the af/ folder with the same file names as the English pages.
  • Images are stored in images/; PNG for illustrations and icons, JPG for photographs.
  • One shared stylesheet (styles.css) and one shared script (script.js).

Accessibility Rules

  • All images have meaningful alt text.
  • Every form field has a visible label.
  • Text and background colours keep strong contrast.
  • A skip link, keyboard-visible focus styles and a lang attribute on every page.
